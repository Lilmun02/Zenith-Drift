# Zenith Drift

Web-based prototype scaffold for **Zenith Drift**, using React for interface composition and Babylon.js for the 3D runtime.

## Requirements

- Node.js 22 or newer
- npm 10 or newer

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

No environment variables or external services are required for the recovery scaffold.

## Current scope

This recovery milestone provides only a verified application shell and a minimal Babylon.js scene. It intentionally contains no gameplay, backend, persistence, or signature mechanic.
